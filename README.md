# 超市库存管理系统 (Supermarket Inventory Management System)

本项目是一款基于 SpringBoot 2.7 与 Vue 3 开发的超市进销存管理系统。系统旨在解决传统超市人工管理效率低、数据不透明、库存预警不及时等问题，实现了从供应商采购到终端销售的全链路数字化管理。

## 1. 系统核心功能
项目共设计并实现了 **18 张数据库表**，涵盖了权限安全、基础数据、进销存业务等核心模块：

*   **用户权限模块**：基于 Spring Security + JWT 实现无状态认证，支持 RBAC（基于角色的访问控制），严格划分管理员、采购员、收银员的权限。
*   **采购管理**：实现“申请-审核-确认入库”的完整闭环，通过 `@Transactional` 保证订单状态与库存变动的数据一致性。
*   **销售管理**：支持快速开单与实时库存扣减，自动生成销售记录。
*   **库存管理**：提供实时库存监控、库存变动日志、以及基于阈值的库存预警提醒。
*   **统计分析**：集成 ECharts 插件，动态展示销售趋势、商品占比及动态业务数据。

## 2. 技术栈选型
本系统坚持“前后端分离”的架构思想，关键技术选型如下：

*   **后端**：Java 8, Spring Boot, MyBatis-Plus, Spring Security, JWT, Redis, MySQL 8.0
*   **前端**：Vue 3, Vite, Vue Router, Pinia, Axios, Element Plus, ECharts
*   **其他**：Lombok, Swagger/Knife4j, BCrypt 加密

## 3. 个人开发亮点
在开发过程中，我重点解决了以下技术问题：
1.  **权限细粒度控制**：通过自定义拦截器与安全上下文，实现了按钮级别的操作权限校验。
2.  **事务一致性保障**：在复杂的入库逻辑中，通过 Spring 事务管理确保了业务数据的原子性，防止了超卖或坏账情况。
3.  **消息通知系统**：自主设计了双向通知机制，当采购单状态变更或库存跌破预警线时，系统会自动向相关角色推送实时通知。
4.  **无状态认证优化**：结合 JWT 与 Redis 白名单机制，在保证安全的前提下提升了系统的响应效率。

## 4. 快速启动
1.  **数据库**：执行 `sql/supermarket配置信息.sql` 初始化数据库。
2.  **后端**：进入 `supermarket-backend` 目录，修改 `application-dev.yml` 中的数据库配置，运行 `SupermarketApplication`。
3.  **前端**：进入 `supermarket-frontend` 目录，执行 `npm install` 随后 `npm run dev`。
